SISTEMA DE GESTIÓN EMPRESARIAL v1.1

INSTRUCCIONES DE EJECUCIÓN

1. Restaurar la base de datos
--------------------------------
Importar el archivo:

backup_bd_v1.1.sql

en MariaDB/MySQL utilizando:
- MySQL Workbench
- phpMyAdmin
- consola MySQL
- o herramienta equivalente.

--------------------------------

2. Configurar conexión
--------------------------------
Verificar credenciales de conexión en la clase:

ConexionBD.java

Ajustar:
- usuario
- contraseña
- puerto
- nombre de base de datos

según entorno local.

--------------------------------

3. Ejecutar sistema
--------------------------------
Ejecutar el archivo:

sistema-gestion-v1.1.jar

Comando:

java -jar sistema-gestion-v1.1.jar

--------------------------------

Tecnologías utilizadas
--------------------------------
- Java
- Java Swing
- MariaDB / MySQL
- Maven
- Git & GitHub
- Power BI
